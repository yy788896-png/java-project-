# AI-Based Tamil Nadu Smart Tourism Portal

A beginner-friendly tourism portal prototype for discovering Tamil Nadu destinations and creating a simple trip plan.

## Features
- Search/filter destinations by name, district, and category
- Sample Tamil Nadu destination catalogue
- Trip planner using destination preferences, number of days, and budget
- Simple chatbot-style tourism FAQ (rule-based demo)
- Responsive layout for mobile and desktop
- No API keys or database required for the demo

## Run locally
This is a static HTML/CSS/JavaScript project.

1. Download and extract the ZIP.
2. Open `index.html` in a browser, or use VS Code with the Live Server extension.
3. To publish it, upload the project files to a GitHub repository.

## Deploy with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Notes
- Destination details are sample content for demonstration. Verify opening hours, fees, travel times, weather, and booking details with official/current sources before travelling.
- The trip planner's costs are illustrative estimates, not live prices.
- The chatbot is a local demo and does not call an AI service. An API-backed AI chatbot can be added later using a server-side backend. Never expose private API keys in frontend code.
